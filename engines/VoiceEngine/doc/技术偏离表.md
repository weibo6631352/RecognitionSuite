# VoiceEngine 技术偏离表

对照 `doc/技术路线.md`。未列入的条款按原路线实现。

| 序号 | 技术路线要求 | 实际做法 | 偏离原因 | 影响 | 是否可回退 |
|---|---|---|---|---|---|
| 1 | Visual Studio 2022 v143 | 使用本机已安装的 **VS 2022 BuildTools + v143**（与 `ScanEngine` 的 `CMakeCache` 相同：`Visual Studio 17 2022` / `v143,host=x64,cuda=.../CUDA/v12.9`）。**不使用 VS 2026 / v145。** | 机器上虽有 VS 2026 Community，但产品工具链必须与 `ScanEngine` 重叠库保持同一版本，避免 Qt 5.12.9 / MSVC CRT 混用。 | 无功能偏离。 | 不需要回退；这是对齐而不是改路线。 |
| 2 | 仓库根目录放置 `技术路线.md` | 文件保持在已有的 `doc/技术路线.md` | 仓库创建时文档已在 `doc/`。 | 仅路径。 | 可复制一份到根目录，非必要。 |
| 3 | 麦克风：WASAPI **或** Qt 音频 | 使用 **WASAPI** | 本机 `C:/Qt/Qt5.12.9/5.12.9/msvc2017_64` 与 `ScanEngine` 同一套 Qt，**未安装 Qt Multimedia**。不能为麦克风单独换 Qt 版本。 | GUI 准实时采集仍满足路线（WASAPI 是明文选项）。 | 若以后给这套 Qt 补上 Multimedia，可再加 Qt 音频后端。 |
| 4 | 固定 llama.cpp 提交 | 锁定 `9731ad3f29da96f588711a0d1eb08cf210721e16`（2026-08-18，libmtmd 已列 Qwen3-ASR-1.7B） | 路线禁止追随每日 HEAD，但未给出提交号。选用当前已验证含 Qwen3-ASR 文档的提交。 | 后续升级需改 pin 并回归。 | 可换成更新的已验证提交。 |
| 5 | 固定 FFmpeg 版本 | BtbN `n8.1.2-44-g7c533d0f86` **LGPL shared**，只链接/发布 `avcodec`/`avformat`/`avutil`/`swresample` | 路线指定 LGPL 动态库和四个组件，未指定版本号。选用 8.1 稳定线和带 SHA 的自动构建。 | 不发布 `avfilter`/`avdevice`。 | 可整包替换同 ABI 的 LGPL shared。 |
| 6 | 模型权重随项目准备 | 权重进 git（Git LFS）。主权重因 GitHub LFS **单文件 ≤2GB** 拆成 `Qwen3-ASR-1.7B-bf16.gguf.part1/part2`，加载时拼成完整 GGUF | 完整 BF16 为 3.88GB，push 被 GitHub 拒绝（`Size must be less than or equal to 2147483648`）。拆分方式与 ScanEngine 的 `model.safetensors.part*` 相同。 | clone 需要 `git lfs`；首次加载会写回完整 `.gguf`。 | 若账号提升 LFS 单文件限额，可改回整文件。 |
| 7 | CER / 标点 F1 / 专有名词“达到验收门槛” | 门槛写在 `docs/BENCHMARK.md`：CER≤0.10，标点 F1≥0.75，专有名词 F1≥0.70 | 技术路线要求达标但 **没有给出数字**。 | 数字可在官方测试集冻结后修订。 | 只改文档阈值，不改架构。 |
| 8 | 连续批量 2 小时、拷到第二台仅驱动机器 | 代码与发布树按此设计；本开发机上的长稳/二机复制若无法跑完，记录在验证日志，不伪造结果 | 验收环境限制，不是实现改道。 | 不降低产品约束。 | 有第二台机器和 2 小时窗口即可实跑。 |
| 9 | CMake `CMAKE_CUDA_ARCHITECTURES=120` | llama.cpp 自动改成 `120a`（RTX 5090） | 上游 ggml 对 Blackwell 的官方映射，仍是 sm_120 族。 | 更贴 5090，不是换架构。 | 可强制写回 `120`，无必要。 |
| 10 | FFmpeg/CUDA 只放在 `runtimes/` 并用 `AddDllDirectory` | 已对 `VoiceEngineCore.dll` 启用 delay-load，并由 GUI、CLI、测试程序在第一次核心 API 调用前注册 `runtimes/ffmpeg` 与 `runtimes/cuda`。CUDA DLL 只保留在私有子目录；FFmpeg 根目录副本暂按现有部署保留。 | 注册发生在核心 DLL 及其 CUDA 依赖解析之前，直接启动 exe 也不依赖系统 `PATH`。 | CUDA 私有目录隔离已消除原偏离。 | 无。 |

## 明确未偏离（与 ScanEngine / 路线重叠部分）

- Qt **5.12.9 msvc2017_64**（与 `ScanEngine` 同一路径）
- CUDA **12.9**，架构 **sm_120**，目标 GPU RTX 5090
- MSVC **v143 /MD**
- 无 CPU ASR、无 WSL、无 Python 推理
- GUI 直接调 `VoiceEngineCore.dll`，不启动 CLI
- FFmpeg 不进系统 PATH
