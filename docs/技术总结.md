# 纸质扫描与语音识别系统技术总结

## 1. 实施范围

当前版本已收敛为两项功能：

- 纸质扫描识别：由 ScanEngine GPU SDK 完成扫描图片识别并生成 Excel；
- 语音识别：由 VoiceEngine GPU SDK完成音频文件识别和麦克风流式转写。

任务计划、电子文档解析、人工业务校对、地面站文件、DTC、图形回放、项目治理及业务验收中心已退出当前产品构建和用户界面。

## 2. 技术架构

系统为 Windows x64、C++17、Qt 5.12.9 桌面应用。宿主仅通过两套公开 SDK 接入识别能力，两套运行时在独立目录部署。系统采用 GPU-only 策略，并串行调度 OCR 与 ASR 重任务。ScanEngine 的就绪检查和识别任务均运行在独立工作进程中，进程结束后由操作系统回收扫描侧 GPU 资源；随后 VoiceEngine 按需自动加载模型，避免两套模型的显存常驻相互污染。

## 3. 功能说明

### 纸质扫描识别

支持 PNG、JPEG、BMP、TIFF 和 WebP 扫描图片。用户选择输入图片和输出目录后启动识别，界面显示进度、Excel 路径和结果目录，并支持取消任务和打开输出目录。

### 语音识别

支持常见音频文件识别和系统默认麦克风流式识别。界面显示临时文本、最终文本和任务进度，并支持加载模型及取消任务。扫描任务释放语音模型后，文件识别、麦克风和语音验收都会在用户触发时自动重新加载模型并继续原操作。

### UI 验收验证

支持在界面中加载双方冻结的扫描或语音验收清单，串行执行全部样本，按统一字符编辑距离计算整套测试集准确率并直接给出 98% 通过、不通过或验证无效结论。样本表格下方内嵌证据面板，可直接查看冻结真值、识别文本、准确率、产物路径、原始结果、置信度来源及 SHA-256，并展示汇总报告与独立哈希校验，不再要求只靠打开目录核验。

界面把“实际准确率”和“模型置信度”分栏展示。模型置信度直接采用模型输出，仅作辅助参考，不参与 98% 判定；正式结论始终由冻结真值评分产生。证据面板还会显示首个计分差异的字符位置与 Unicode 码点，便于识别全角/半角等肉眼不明显的差异。每次运行使用唯一目录，保存清单、输入、语音原始字节结果、扫描中间产物和汇总报告的 SHA-256 证据链；验证首尾还会把实际部署的 SDK、模型、DLL、配置和运行时文件逐项与编译时发布基线锚点比对。模型或证据不匹配、缺少置信度证据，或没有与报告匹配的 `SHA256SUMS.txt` 时只能判为“验证无效”。

## 4. 验收目标

1. 软件整体运行稳定，两项功能运行完好；
2. 纸质扫描识别率达到 98%；
3. 语音识别率达到 98%。

准确率结论必须由双方确认的代表性冻结测试集、真值文本和统一计分脚本产生。当前 SDK 就绪检查与功能烟测只能证明软件可运行，不能单独证明 98% 指标已达成。

## 5. 稳定性边界

建议正式测试覆盖连续批次、长音频、麦克风启停、任务取消、损坏文件、无 GPU、模型缺失和程序退出等场景，并保留版本、硬件、数据集和结果记录。
