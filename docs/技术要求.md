# 纸质扫描与语音识别系统——技术要求

## 一、当前建设范围

本阶段仅建设以下两项识别能力：

1. 纸质扫描识别：对纸质资料的扫描图片进行文字与表格识别，并输出可查看、可使用的结构化结果；
2. 语音识别：对音频文件及麦克风语音进行转写，并输出识别文本。

业务流程尚未明确，因此任务计划、电子文档解析、人工业务校对、地面站格式生成、DTC 加载、多维验证、图形回放及其他业务模块暂不建设，也不纳入本阶段验收。

## 二、技术要求

1. 软件整体运行稳定，两项识别功能运行完好，系统整体符合当前设计要求；
2. 纸质扫描识别率达到 98%；
3. 语音识别率达到 98%。

## 三、指标口径

98% 为正式验收目标，不以单张图片或单段音频的演示结果代替统计结论。

- 纸质扫描识别率：建议以冻结测试集上的字符准确率统计；
- 语音识别率：建议以冻结测试集上的 `1 - CER`（字错误率）统计；
- 双方应在验收前确认测试集、真值、样本范围、标点是否计分，以及数字、日期、单位等文本归一化规则；
- 稳定性应覆盖程序启动、SDK 检查、连续识别、任务取消、异常输入和正常退出。

## 四、交付物

1. 纸质扫描与语音识别系统 1 套；
2. 技术总结及测试记录。
